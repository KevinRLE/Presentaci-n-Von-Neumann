Memoria Principal

El modelo de Von Neumann utiliza la memoria principal para almacenar datos e instrucciones.

¿Qué es la Memoria Principal?

La Memoria Principal (también llamada memoria central o RAM) es el componente del modelo de Von Neumann encargado de almacenar, mientras el equipo está encendido, tanto los datos como las instrucciones de los programas que la CPU está ejecutando en ese momento.

  • Único espacio compartido: a diferencia de otros modelos, guarda datos e instrucciones juntos, sin distinguirlos; es la CPU quien interpreta qué es cada cosa.
  • Acceso aleatorio: cada posición tiene una dirección única y puede leerse o escribirse en cualquier orden, sin importar su ubicación física.
  • Volatilidad: la memoria RAM pierde su contenido al apagarse el equipo; existe también memoria ROM, no volátil, para datos permanentes.
  • Rapidez y capacidad: es más veloz que el almacenamiento secundario (disco), aunque de menor capacidad.

¿Cómo funciona?

La memoria se organiza en celdas numeradas por direcciones. La CPU se comunica con ella mediante tres buses, y cada operación de lectura o escritura sigue una secuencia de pasos:

1

La Unidad de Control coloca la dirección de memoria que necesita en el bus de direcciones.

2

Se envía una señal de lectura o escritura a través del bus de control, indicando la operación a realizar.

3

Si es lectura, la memoria coloca el contenido de esa dirección en el bus de datos para que la CPU lo reciba; si es escritura, la CPU envía el dato para guardarlo.

4

El Contador de Programa (PC) avanza a la siguiente dirección, y el ciclo de instrucción se repite.
