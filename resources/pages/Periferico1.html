¿Qué es un Periférico de Entrada?

Un periférico de entrada es cualquier dispositivo que permite al usuario introducir datos o instrucciones en la computadora. El teclado es el periférico de entrada más común.

¿Cómo funciona el teclado?

1

El usuario presiona una tecla física

2

El teclado genera un código de escaneo (scan code)

3

El controlador convierte el código a ASCII/binario

4

Los datos viajan a la CPU a través del bus de E/S

📊 Conceptos Clave

ASCII American Standard Codificación de 7-8 bits
IRQ Interrupción Avisa a la CPU
Bus E/S Canal de datos
Buffer Memoria temporal Almacena pulsaciones
